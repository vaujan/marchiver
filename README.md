# marchiver

Mark and archive things from the web.

A desktop app for offline-first bookmark and image collection with folder/tag organization.

## Stack

- Electron + React + TypeScript + Tailwind CSS + shadcn/ui
- SQLite via `better-sqlite3`
- `pnpm` + `electron-vite`

## Development

```bash
pnpm install
pnpm dev       # Development with hot reload
pnpm build     # Production build
pnpm preview   # Preview production build
```
