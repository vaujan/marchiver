# Plan: Create `electron-shadcn-starter` Scaffold

## Goal

Create a clonable GitHub template repo: Electron 42 + React 19 + TypeScript 5.8 + shadcn/ui (base-rhea, mist, phosphor) + Tailwind CSS v4. Includes full AI agent infrastructure (AGENTS.md, skills, skills-lock.json) and a working Notes example app demonstrating the full IPC pattern.

## Bug Fix

marchiver has renderer code at `src/types/renderer/` but the `@/` alias points to `src/renderer/` (which doesn't exist). The starter puts all renderer code at `src/renderer/` and fixes this.
